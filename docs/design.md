# 青蛙跳板设计

初稿 2026-11-20。产品在 Windows 桌面提供划词、截图和当前剪贴板三个入口。本文记录产品约定；构建和实测状态见 [迭代记录](iterations.md)。

## 从正在做的事出发

| 场景 | 触发和结果 | 验收要点 |
| --- | --- | --- |
| 阅读可选文字 | 选中文本，点击附近的翻译入口，或按智能翻译热键 | 在原应用上方看到译文，原剪贴板仍可粘贴 |
| 阅读图片、扫描 PDF 或字幕 | 智能翻译无法读取选区时，框选屏幕的一部分 | 松手后只提交指定区域；可以取消 |
| 沟通报错 | 截图热键，框选，圈出按钮，画箭头，输入中文，遮住账号，回车 | 粘到聊天窗口的图与确认时的画面一致 |
| 标注已有图片 | 复制图片，呼出剪贴板面板，选择继续标注 | 复用同一个编辑器，支持保存 PNG 或复制 |
| 处理长文本 | 复制一段文字，打开面板，运行自定义动作 | 新增“一句话总结”后即可使用，无需重新打包 |

## 界面和输入

托盘负责常驻和退出。工作台展示这次输入的内容、可用动作和结果。空剪贴板、无模型、请求失败各有独立状态。关闭窗口回托盘，重新触发入口时取一份新的输入快照。

划词浮窗与工作台共用一个原生窗口。「返回工作台」在原位置和尺寸内切换视图，保留选中的文字、翻译进度或结果，以及已填写的附加指令。在工作台点击刷新只更新剪贴板快照。关闭浮窗时直接隐藏，之后从托盘或全局热键再次唤起工作台，恢复此前的工作台布局。

两个视图共用工作台的默认尺寸 800×600（逻辑像素）。本次运行中调整窗口大小后，两处都沿用新尺寸。普通窗口划词时移到指针附近，工作台已最大化时继续在当前显示器最大化展示。

普通截图和截图翻译共用冻结画面，按下不同热键决定松手后的行为。截图编辑器提供矩形、椭圆、箭头、画笔、文字、马赛克、实心遮挡。底图使用原始物理像素；选区和标注保留为对象。光标的逻辑坐标通过当前显示比例映射到图像坐标。复制、保存、图片模型请求均通过同一份合成图，确保遮挡随导出一起生效。

默认在鼠标所在显示器框选。多屏各自使用本屏原点和缩放系数；跨屏拼接作为独立需求评估。密码输入、系统安全桌面或受保护内容尊重操作系统限制。读取选区失败时直接进入用户可见的框选步骤。

## 结构与技术决策

模型结果在工作台、划词浮窗和提示词试跑中使用同一个 Markdown 视图。剪贴板预览和划词原文按输入展示。结果卡的复制按钮保留模型输出中的 Markdown，便于粘贴到笔记或编辑器。结果中的 HTML 当作文字展示，图片引用仅显示说明，链接显示标签并可悬停查看地址。

- Rust 与 Tauri 2 负责托盘、热键、原生采集、文件保存和模型请求。Windows 使用 WebView2。发布体积按实际产物记录，目标为已有 WebView2 环境下 x64 安装包小于 15 MB。
- React + TypeScript 实现工作台、截图编辑器、设置。编辑状态放在当前会话，切换输入后旧请求的结果不得覆盖新内容。
- `src/editor` 维护图片坐标、标注和导出。`src/models` 维护模型与提示词界面。`src-tauri/src/desktop` 封装取词、捕获和剪贴板。`src-tauri/src/models.rs` 管理配置、凭据和服务调用。`src-tauri/src/shell.rs` 管理应用生命周期与全局快捷键。
- 正常链路按「获取输入 → 展示快照 → 执行动作 → 展示或导出结果」推进。快捷翻译是用户明确授权直接运行动作的特例。图片只在选择视觉动作后发送给所选服务。

## 模型与个人动作

历史列表以输入内容为主。文字预览最多显示两行，图片显示当次输入的缩略图，动作和完成时间放在下方。首次查看图片时依次从原图生成缩略图并缓存，兼容已有记录。恢复操作始终使用完整快照。

工作台的「历史记录」按完成顺序列出最近 30 次成功的模型操作，包括划词翻译、图片翻译、提取文字与自定义动作。设置中的试跑仅用于调试。每条记录包含送给模型的文字或合成图片、动作名称与编号、当次附加指令、原始 Markdown 结果和完成时间。恢复记录只切换工作台快照，用户可以离线查看结果，再选择当前可用的动作。WebView2 的 IndexedDB 分开保存列表摘要与完整内容，写入和淘汰最旧记录在同一事务中完成。

展开「附加指令」时，提交操作会将输入框中的要求追加到此次请求的动作提示词，文字或图片仍作为独立输入。收起输入框即可暂时停用，新输入从空白开始，恢复历史时可修改原有要求。

模型配置保留 API 地址、模型 ID、显示名和图片能力。文本与图片可以使用不同的默认模型。密钥写入 Windows 凭据管理器。支持 Chat Completions 和 Responses，服务地址可使用 HTTP 或 HTTPS。根路径按 Chat Completions 调用，只有网关明确拒绝该渠道的协议时才向同源 Responses 路径重试一次；成功的选择缓存在当前进程内。指定完整接口路径可以固定协议。SSE 流收到完成事件后展示最终文本。

动作定义输入类型、名称、提示词和可选的指定模型。默认包含文本翻译、图片翻译、文字提取、总结和润色。用户可以复制现有动作，改写提示词，也可以添加独立的动作。文本翻译、图片翻译和提取文字的输入类型保持稳定，保证截图工具栏和划词入口在修改设置后仍可调用。指定模型被删除或与输入不兼容时，使用对应输入类型的默认模型。模型响应作为结果文本显示；保存、写剪贴板等本地操作由用户触发。
