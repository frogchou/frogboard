# 迭代记录

## 0.1.10 · 悬浮反馈与标签页对齐

工作台、会话、设置、操作历史和截图编辑器统一使用悬浮气泡显示操作反馈。会话删除确认浮在删除按钮下方。三个工作区标签共用宽度、留白和滚动条占位。

在 540、800、985 和 1440 像素宽的窗口中，核对带滚动条的工作台、历史记录与会话的标签栏和正文边界。用模拟剪贴板验证连续复制、失败、自动关闭、手动关闭，比较反馈出现前后的正文、按钮坐标与滚动位置。

## 0.1.9 · 剪贴板会话

新增「会话」标签和「加入会话」按钮，支持带文字或图片新建会话、连续追问、本地保存、恢复和删除。附加指令可作为首条问题的草稿。发送失败或中断后可以重试，也可以修改提问。

用演示内容验证了多轮消息顺序、图片上下文、Markdown 显示、重新载入后恢复、切换会话时回复归属、删除后的迟到回复、失败重发和窄窗口布局。原生测试检查 Chat Completions 与 Responses 的多轮请求格式。

## 0.1.8 · 通用设置与托盘双击

新增开机启动、主题和操作历史开关。登录启动后驻留托盘，左键双击托盘图标可直接读取剪贴板并显示工作台。浅色、深色和跟随系统即时生效，重启后保留选择。

在 Windows 测试窗口发送系统托盘双击消息，确认隐藏的工作台可被唤起。在临时注册表位置验证开启、关闭、重复关闭、含空格与中文的路径及已被系统禁用的启动项。用独立浏览器验证主题切换、系统主题变化和重新载入，并核对暂停记录期间已有历史仍可读取。

## 0.1.7 · 划词与工作台共用窗口尺寸

划词翻译沿用工作台当前大小，默认由 540×390 增至 800×600。两种视图内的手动调整在本次运行中共享，连续划词和返回工作台都保留该尺寸。工作台已最大化时，划词翻译也以最大化显示。

Windows 原生窗口回归覆盖默认大小、工作台调到 880×620、译文窗口调到 840×610 后连续划词，以及最大化状态。关闭时核对窗口位置与大小，重新唤起后核对工作台位置和共享尺寸。

## 0.1.6 · 划词返回与历史预览

划词翻译增加「返回工作台」按钮，原地切换且保留当前原文和译文。工作台内刷新剪贴板沿用当前窗口布局。历史列表突出输入文字或图片缩略图，操作名称和时间移至次行。已有图片记录首次展示时自动生成缩略图。

用模拟译文验证划词按钮和智能翻译热键两种文本入口：在请求进行中或已完成时返回，核对输入、附加指令、模型调用次数和 540×390 视图尺寸。使用旧版格式的图片记录验证缩略图、重载与完整原图恢复。Windows 原生窗口回归另行核对了关闭后再唤起的普通和最大化布局。

## 0.1.5 · 操作历史与附加指令

工作台增加历史记录标签，重启后可调回最近 30 次已完成的模型操作。恢复文字、图片、结果与当次指令后可继续处理。工作台动作、智能翻译和截图编辑器里的模型操作共用记录流程。附加指令支持文本和视觉模型，两种接口协议使用相同的组合规则。

用独立浏览器配置和模拟模型验证重启后恢复文字、原图、Markdown 结果与指令，恢复时模型调用数为零。在恢复图片后编辑附加指令并执行自定义操作，检查实际提交的图片和指令。连续完成 31 次翻译后，列表与完整快照均只保留最新 30 条。原生端使用本地模拟服务核对了两种协议中的提示词和文字、图片载荷。

## 0.1.4 · 模型结果排版

工作台、划词翻译和提示词试跑共用 Markdown 结果视图。标题、强调、列表、引用和表格直接排版，代码块保留缩进并可横向滚动。纯文本保留换行，结果卡右上角的复制按钮复制模型返回的原文。

使用含中文标题、JSX 和表格的模拟结果走通三个入口，并逐字核对复制内容。在 540×390 的浮窗中，长代码行可在代码块内部横向滚动。

## 0.1.3 · 关闭划词窗口

修复关闭划词浮窗时剪贴板工作台一闪而过的问题。点击标题栏关闭按钮或按 Esc 会先隐藏浮窗，再清理本次翻译。下次打开工作台时恢复原来的位置、大小和最大化状态。

在独立 Windows 窗口使用系统标题栏关闭命令复现旧版从 540×390 恢复为 800×600 的问题。修复后，普通和最大化两种布局均通过关闭、重新打开的回归测试。浏览器测试另行验证了 Esc 等待原生窗口隐藏后才清空译文，迟到的关闭通知不会清除下一次划词。

## 0.1.2 · Codex 渠道的翻译与图片识别

支持 Responses 接口的文字与图片输入，以及完整 JSON 或 SSE 结果。填写服务根路径时优先使用 Chat Completions；若网关明确返回 Codex 渠道不支持该路由，则对同一服务切换到 Responses，成功后在本次进程中复用。通用 500、超时和鉴权失败均不会触发协议切换。填写完整的 `/v1/responses` 可以直接指定协议。

模型服务返回错误时，工作台和提示词试跑显示所用模型、HTTP 状态码，以及服务返回的简短 JSON 错误说明。服务端故障和限流可以直接重试；涉及本机模型配置、接口或认证的问题提供模型设置入口。错误说明限制长度，隐藏本次请求所用的密钥。

回归测试从保存的配置分别解析文字翻译、图片翻译和图片识别的目标模型，并用本机模拟服务验证 HTTP 500 的显示。

## 0.1.1 · 自定义模型接口

修复远程 HTTP 接口在保存模型配置时被拒绝的问题。前端和桌面端都接受带端口的域名、IPv4、IPv6 地址。填写服务根路径时自动补齐 `/chat/completions`，填写完整请求路径时保留该路径。继续禁止 URL 中的凭据、查询参数和片段。

### 本轮已验证

- 7 项编辑器单元测试覆盖反向框选、边缘裁剪、八个调整手柄、撤销快照及 Shift 约束。Chromium 以 150% 像素比验证了圈画、中文多行重编辑、撤销重做，并比对四个出口的合成 PNG。
- 8 项 Rust 测试覆盖快捷键冲突、屏幕与剪贴板位图转换、透明度、服务地址、图片输入、动作模型选择、旧设置恢复以及一次本机模拟服务请求。
- 已处理三个联动问题。复制改过的剪贴板图片后，工作台保留合成图；切换热键时旧编辑器按快照编号结束；新输入读取失败会清除旧内容并展示错误。
- 已启动 Windows 发布版，在真实 WebView2 窗口中切换工作台、模型、提示词及快捷键设置；使用临时纯色窗口验证了冻结截图、全图选区、标注工具栏与退出编辑。脚本见 [Windows 桌面联测](../scripts/windows-smoke.ps1)。
- 自动构建配置用于 GitHub 的 Windows runner。本机已通过 TypeScript 发布构建、Rust 格式与 Clippy 检查。远端工作流的运行结果应以实际上传后的 Actions 记录为准。

### 本轮边界

翻译结果在服务响应完成后显示。真实模型的翻译质量、服务计费和响应时间取决于使用者选择的服务。Windows 安装包使用系统 WebView2，支持在单一显示器内框选；不同 DPI 的双屏以及真实中文输入法候选窗口列入后续实机验收。
